## About Me

I am a third-year PhD student at the State Key Laboratory of Processors, Institute of Computing Technology, Chinese Academy of Sciences, supervised by Li Lian, Tang Hongwei, and Li Haofeng.

Previously, as an undergraduate at Shandong Agricultural University, I conducted research on machine learning and embedded systems under the supervision of Professor Zhang Yan in the Smart Agriculture Laboratory.

My research focuses on LLM inference acceleration, foundation models, and embodied intelligence. I am particularly interested in efficient model architectures, large models for security applications such as static analysis, and world action models.

## Research Interests

- **Efficient LLMs** — placing model parameters and allocating computation more efficiently.
- **World Action Models** — reducing hallucinations in autoregressive models by grounding them in the physical world.
- **AI for Security** — developing practical model designs, benchmarks, and training techniques for tasks such as static code analysis.
- **Multi-Agent Systems** — studying memory mechanisms for multi-agent systems.

## Selected Research(only firsrt author)

### [Meta-Learning Where to Allocate Experts: Task-Conditioned Layer-Wise Compression for MoEs](https://openreview.net/forum?id=MD6lEVNSe6)

MetaNet-MoE uses a support-set controller for task-conditioned, layer-wise expert allocation in frozen sparse Mixture-of-Experts models. It predicts per-layer expert budgets and bounded routing biases without changing the backbone or the original router parameters.

`Mixture-of-Experts` · `Meta-Learning` · `Efficient Inference`

[Paper](https://openreview.net/forum?id=MD6lEVNSe6) · [Code](https://github.com/Notletterday/MetaNet-MoE) · [Design Notes](https://github.com/Notletterday/MetaNet-MoE/blob/main/docs/DESIGN.md)
